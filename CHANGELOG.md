# Changelog

All notable changes to ChatPlus are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Human-friendly release notes also appear on the
[public changelog page](https://origin-technology-co-ltd.github.io/chat-plus/changelog.html).

## [0.1.0] - 2026-07-29

### Added

- First public desktop release for macOS (Apple Silicon), Windows, and Linux.
- Local-first AI chat with threaded conversations, ambiguity bypasses, Markdown tree export, and context-depth controls.
- GitHub Releases installers with stable asset names for direct download links.
